Privacy

This site collects nothing about you.

No tracking

portolaan.com sets no cookies, runs no analytics, shows no advertising and loads nothing from other servers: fonts, images and scripts are all served from this site.

Your theme choice

If you switch between dark and light, that preference is stored in your own browser (local storage) so the site remembers it. It never leaves your device, and you can clear it at any time.

Email

If you write to arthurwyy@gmail.com, your message and address are used only to reply to you, are not shared with anyone, and are not added to any mailing list.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub may process technical request data (such as IP addresses) to deliver the pages securely; see GitHub's own privacy statement.
